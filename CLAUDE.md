## Obsidian Vault — Grounding Layer

This project uses `valt/` as its persistent knowledge base.
**Read these files at the start of every session, before writing any code:**

- `valt/index.md` — map of the entire vault (start here)
- `valt/overview.md` — what the project does, stack, current status
- `valt/conventions.md` — coding standards, naming, TDD rules, error handling
- `valt/decisions.md` — architectural decisions and their rationale

**Maintenance rules (enforce always):**
- Every new architectural decision → append to `valt/decisions.md`
  using the template at `valt/templates/decision.md`
- Every resolved bug → save to `valt/debugging/YYYY-MM-DD-title.md`
  using the template at `valt/templates/debugging.md`
- Every reusable pattern discovered → save to `valt/snippets/title.md`
  using the template at `valt/templates/snippet.md`
- After each session with significant changes → update
  `valt/overview.md` status block with what was done
- After every vault write → update `valt/index.md` counts and file list
- Never let the vault become stale. If you find outdated info, fix it.

**Import note:** This vault was generated by vault-import on 2026-04-26
by reading the existing codebase. Conventions and decisions marked ⚠️ or ❓
should be reviewed and confirmed manually before being treated as ground truth.
