# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.x     | ✅        |

## Reporting a vulnerability

**Do not open public issues for vulnerabilities.**

Use [GitHub's private vulnerability reporting](https://github.com/SEU-USUARIO/ferres-db-core/security/advisories/new)
or send an email to `seu-email@dominio.com`.

Response within 72 hours. Coordinated disclosure within 90 days.
